# bga-tools

Userscripts for [Board Game Arena](https://boardgamearena.com). Install a userscript manager
([Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/)),
then open an install link below. Installed scripts update automatically from this repo.

| Script | Description | Install |
| --- | --- | --- |
| BGA Game Stats (Ark Nova + Forest Shuffle) | Collects finished Ark Nova and Forest Shuffle tables from Board Game Arena and posts them to your game stats server. | [bga-stats.user.js](https://raw.githubusercontent.com/gergi/bga-tools/main/gamestats/bga-stats.user.js) |
| BGA Forest Shuffle: symbol counts in player panels | Shows per-player tag and tree-symbol counts for Forest Shuffle on Board Game Arena, like the Smoky Mountains version does. | [forest-shuffle-tags.user.js](https://raw.githubusercontent.com/gergi/bga-tools/main/forest-shuffle/forest-shuffle-tags.user.js) |

### Single-game builds

Same as the combined Game Stats script, limited to one game. Install either the combined
script or one of these, not both.

- [BGA Game Stats: Ark Nova](https://raw.githubusercontent.com/gergi/bga-tools/main/gamestats/bga-stats-arknova.user.js)
- [BGA Game Stats: Forest Shuffle](https://raw.githubusercontent.com/gergi/bga-tools/main/gamestats/bga-stats-forestshuffle.user.js)

Published automatically from private source repos; do not edit files here by hand.
